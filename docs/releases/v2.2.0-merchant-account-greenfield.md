# Release v2.2.0 — Merchant Account Greenfield

**Data:** 2026-07-03  
**Tag sugerida:** `v2.2.0-merchant-account-greenfield`  
**Branch:** `release/changing-arch-renaming-db` (ou `main` após merge)

---

## Resumo

Esta release consolida a **initiative merchant-account (MA0–MA9)**: o produto deixa o modelo legado `tenants` / database-per-store e passa a operar com **conta merchant → N lojas**, banco físico `atacommerce_<merchant_slug>`, schema PostgreSQL em **inglês** e cutover **greenfield** (sem migração de dados legados).

Na mesma linha de entrega: **vitrine e admin** migrados para **shadcn/ui** com tokens Ata, correção de CSS na storefront, rename `@lojao/store-host`, e **pipeline CI verde** (test + e2e-smoke 66/66).

## Breaking changes

> **Não há upgrade in-place do banco legado.** Produção existente exige janela de manutenção, backup frio e reset greenfield.

1. **Tabela `tenants` removida** — usar `merchants` + `stores`.
2. **Header de vitrine** — `X-Tenant-Slug` → **`X-Store-Slug`**.
3. **Signup público** — `/public/signup` legado removido; usar **`POST /public/merchant-signup`**.
4. **Seed dev** — `seed-dev.mjs` (PT/tenant) substituído por seed MA8 (`test-loja` / `loja`).
5. **Env legado** (ainda aceitos como fallback em alguns apps, preferir novos):
   - `BOOTSTRAP_MERCHANT_SLUG` / `BOOTSTRAP_STORE_SLUG` no boot da API
   - `NEXT_PUBLIC_DEFAULT_STORE_SLUG` na vitrine
   - Deprecados: `TENANT_SLUG`, `BOOTSTRAP_TENANT_SLUGS`, `VITE_TENANT_SLUG`
6. **Dados legados** — clientes e pedidos antigos **não** são importados; recadastro na arquitetura nova.

## Deploy greenfield (produção)

1. Backup completo do Postgres (`pg_dump`) — rollback = restore + deploy anterior.
2. Reset do master: migrations Drizzle `0000`…`0005` (+ MA7 billing se aplicável).
3. Remover bancos físicos legados (`lojao_*`, tenants isolados).
4. Deploy API + admin + storefront desta tag.
5. Configurar `BOOTSTRAP_MERCHANT_SLUG` ou signup manual.
6. Platform: `MASTER_EMAIL` / `MASTER_PASSWORD`.

Detalhes: [`docs/migration/runbooks/ma8-cutover.md`](../migration/runbooks/ma8-cutover.md), [`docs/migration/DEPLOY.md`](../migration/DEPLOY.md).
